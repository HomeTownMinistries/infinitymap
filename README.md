# InfinityMap.org

The website for **The Infinity Map** — a comprehensive life & legacy planning system from HomeTown Ministries International.

> "Because love plans ahead."

## Structure

- `index.html` — the entire site (single static page, no build step)
- `assets/` — logo, mark, favicon, and cover art

## Deployment

This repo is deployed via [Netlify](https://www.netlify.com/) at [infinitymap.org](https://infinitymap.org). Pushing to `main` publishes the site automatically once the Netlify site is linked to this repository (Site configuration → Build & deploy → Link repository). No build command is needed; the publish directory is the repo root.
